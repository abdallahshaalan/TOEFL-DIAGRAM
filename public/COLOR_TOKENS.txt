================================================================================
UI/UX PORTFOLIO — COLOR TOKEN REFERENCE
================================================================================
Source of truth : app/globals.css  (:root / .dark runtime tokens)
Bootstrap       : @theme { } at top of globals.css (mirrors brand + neutrals)
Email sync      : lib/brand-colors.ts  (hex only — emails cannot read CSS vars)
Handoff guide   : docs/HANDOFF.md

Last aligned with globals.css brand/glass/navbar/toast/service tokens.

--------------------------------------------------------------------------------
HOW TO REBRAND (simple)
--------------------------------------------------------------------------------
1. Edit :root  → section "BRAND HANDOFF (light)"
2. Edit .dark  → section "BRAND HANDOFF (dark)"
3. Mirror the same --brand-* hex values in the top @theme block
4. Sync lib/brand-colors.ts (primary, accent, secondary, tertiary, ctaHover, …)

Derived tokens (--primary, --ring, --brand-glow*, charts 1–3, etc.) AUTO-FOLLOW.
Do NOT hardcode blue/violet RGBA in components — use var(--brand-*) / Tailwind.

HANDOFF        = change these for a new designer brand
LEAVE ALONE    = neutrals, status, service artwork (unless full theme redesign)

2. BRAND GLOWS (DERIVED) — ambient washes, not solid fills
================================================================================
These use color-mix() from --brand-primary / --brand-secondary.
Used by PremiumBackground, heroes, nav spotlights.

TOKEN                        MIX (typical)                         PURPOSE
--------------------------------------------------------------------------------
--brand-glow                 primary 12% + transparent             Default ambient blue
                                                                   wash
--brand-glow-soft            primary 6% (light) / 7% (dark)        Softer radial wash
--brand-glow-mid             primary 9%                            Mid-strength glow /
                                                                   orbs
--brand-glow-strong          primary 20%                           Stronger spotlight /
                                                                   hero bloom
--brand-glow-subtle          primary 4% (light) / 5% (dark)        Barely-there tint
--brand-secondary-glow       secondary 8%                          Violet ambient
                                                                   companion
--brand-secondary-glow-soft  secondary 5%                          Softer violet wash

CSS usage examples:
  background: var(--brand-glow);
  bg-[radial-gradient(...,var(--brand-glow-strong),transparent)]

17. TAILWIND / CSS USAGE CHEAT SHEET
================================================================================
Prefer semantic utilities (they read :root / .dark via @theme inline):

  bg-background          text-foreground
  bg-card                text-card-foreground
  bg-primary             text-primary-foreground
  bg-accent              text-accent-foreground
  bg-muted               text-muted-foreground
  bg-secondary           text-secondary-foreground
  border-border          border-input
  ring-ring              outline / focus rings
  bg-destructive         text-destructive

Arbitrary / raw CSS when needed:

  var(--brand-primary)
  var(--brand-glow) / var(--brand-glow-strong)
  var(--glass-bg) / var(--glass-border) / var(--glass-highlight)
  var(--navbar-bg) / var(--navbar-control-bg)
  var(--cta-hover)
  color-mix(in srgb, var(--brand-primary) 18%, transparent)

AVOID for brand:
  bg-blue-600, #2563EB hardcoded, rgba(37,99,235,…) in components
