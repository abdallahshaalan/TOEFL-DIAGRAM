BLUE BRAND • RECOMMENDED NOTIFICATION SYSTEM

One glass surface.
Clear semantic meaning.

🏆 Recommended visual direction

Do not create five different colored notification cards. Keep the surface neutral and consistent; use color intentionally for meaning.

🧩 System rules

🪟 Shared glass surface

Every notification uses the same neutral frosted surface so the system feels cohesive and premium.

🔵 Blue = product feedback

Use the primary brand blue for default and loading states, not for every notification.

🎯 Color = meaning

Green, blue, orange, and red remain stable semantic signals. Do not repurpose them arbitrarily.

👁 Icon + text

Never depend on color alone. The icon and message must communicate the notification state independently.

🌙 Dark mode adaptation

Keep exactly the same architecture. Only the glass surface and semantic shades adapt to your existing dark tokens.

/* LIGHT — recommended toast surface */ --toast-bg: rgba(255, 255, 255, .82); --toast-border: rgba(255, 255, 255, .95); --toast-shadow: 0 16px 42px rgba(0, 0, 0, .10); /* DARK — recommended toast surface */ --toast-bg: rgba(21, 21, 21, .78); --toast-border: rgba(255, 255, 255, .10); --toast-shadow: 0 20px 50px rgba(0, 0, 0, .45); /* SEMANTIC COLORS */ default/loading: var(--brand-primary); success: var(--success); info: var(--info); warning: var(--warning); error: var(--destructive);
FINAL RECOMMENDATION

Blue for the brand. Semantic colors for meaning.

This gives the project a clean, globally recognizable notification system without losing the premium visual identity. The glass surface provides consistency; semantic accents provide instant comprehension.
